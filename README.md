## ما في هذا المستودع

| الملف | الوظيفة |
|---|---|
| `index.html` | الموقع كاملاً: التصميم والنصوص وبيانات المشاريع |

| `.github/workflows/pages.yml` | النشر التلقائي: كل تعديل يُرفع هنا يظهر على الموقع خلال دقيقة إلى دقيقتين |

## كيف أطوّر الموقع مستقبلاً (بدون برمجة)

1. افتح **https://claude.ai/code**
2. ابدأ جلسة جديدة، واختر المستودع **pesglass019-ui/alutal**.
3. اكتب طلبك بالعربي وأرفق الصور **في رسالة جديدة**. أمثلة:
   - «اضف مشروع فيلا فلان في حي الشاطئ بجدة» + الصور
   - «عدّل رقم الجوال في صفحة تواصل معنا»
   - «اضف صفحة جديدة للوظائف»
   - «اضف خدمة جديدة: أبواب أوتوماتيكية»
4. Claude يقرأ المهارة تلقائياً، فيعرف طريقة إضافة المشروع وتحسين الصور، ويختبر الموقع، ثم ينشره.

### نصائح

- أرسل الصور كمرفقات في **رسالة جديدة**، لا أثناء ما يعمل Claude على طلب سابق.
- اذكر مع كل مشروع: **الاسم، الحي والمدينة، العميل، ونوع الأعمال**. وإن توفرت: المساحة، القيمة، السنة.
- لن يكتب Claude أرقاماً أو معلومات لم تعطه إياها.
